# My Literary Journey: A Great Books Digital Portfolio

Final project for **Great Books** at the University of Nueva Caceres. This is a digital website portfolio by **James Manuel An** (BS Information Technology, 4th Year).

## Sections
1. **Student Profile**
2. **Compilation of Seven Literary Analyses**
   - Voice Out of the Whirlwind (Job 38): Moralist–Philosophical
   - The Panchatantra: Formalist
   - The Iliad: Archetypal
   - The Tale of Genji: Feminist
   - Pride and Prejudice: Marxist
   - Les Misérables: Psychoanalytic
   - To Kill a Mockingbird: Historical–Sociological
3. **My Favorite Literary Masterpiece**: Voice Out of the Whirlwind (Job 38)
4. **Summary of Learning**
5. **Personal Reflection**

## Tech
A single static page built with plain HTML, CSS and JavaScript. It uses hash-based navigation and has no build step. Open `index.html` in a browser, or host it with GitHub Pages.
